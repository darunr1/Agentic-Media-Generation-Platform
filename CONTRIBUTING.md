# Contributing

Use pnpm and Node 20+. Keep TypeScript strict, validate trust boundaries with Zod, preserve workspace filters, and test domain rules. Provider types stay inside adapters. Never commit `.env`, tokens, generated media, customer content, or cloud credentials.

Before a pull request run format, lint, typecheck, tests, and builds. Describe migrations, security impact, provider scopes, rollout/rollback, and manual platform steps. TODOs are reserved for external credentials, paid accounts, or platform approval and must name the dependency.
