# Roadmap

The local journey and production boundaries are implemented. External enablement follows official approval: Stripe test mode, Instagram review, YouTube verification, then optional Facebook/Threads/TikTok/X apps. Future increments can add production GCS/Cloud Tasks/email adapters, richer Remotion templates, malware scanning, native PDF extraction, white-label domains, SSO/SCIM, and statistically powered experiments. None are represented as active before validation.
